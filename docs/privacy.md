# Dataset Privacy and Publication Record

The repository contains human voice recordings. The project owner confirmed that all recorded speakers consented to public redistribution. The dataset is published under CC BY 4.0.

The project owners should retain the original consent record privately. It should establish that:

- participants consented to public redistribution;
- participants understood that voice can be identifying;
- consent covers raw recordings and derived model artifacts;
- speaker identifiers do not expose names or student IDs; and
- participants can contact the project owners to request removal.

The source code and dataset use separate licenses. See the root `LICENSE` and `data/LICENSE.md`.
